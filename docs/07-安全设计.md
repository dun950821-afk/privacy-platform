# 安全设计

## 1. 身份认证与授权

### 1.1 认证
- JWT Token认证 (access_token 30min + refresh_token 7d)
- 密码bcrypt哈希存储
- MVP本地账号，预留LDAP/OIDC接口

### 1.2 RBAC权限模型
角色: platform_admin, rule_admin, project_owner, tester, developer, compliance, auditor

权限矩阵:
| 角色 | 项目 | App | 任务 | 问题 | 规则 | SDK库 | 系统 | 证据下载 |
|------|------|-----|------|------|------|-------|------|---------|
| platform_admin | 全部 | 全部 | 全部 | 全部 | 全部 | 全部 | 全部 | 是 |
| rule_admin | 读 | 读 | 读 | 读 | 读写 | 读写 | - | 否 |
| project_owner | 所属 | 所属 | 所属 | 所属 | 读 | 读 | - | 是 |
| tester | 所属 | 所属 | 所属 | 读写 | 读 | 读 | - | 是 |
| developer | 所属 | 所属 | 读 | 读写(整改) | 读 | 读 | - | 否(脱敏) |
| compliance | 所属 | 所属 | 读 | 读 | 读 | 读 | - | 是 |
| auditor | 全部 | 全部 | 读 | 读 | 读 | 读 | 读 | 否 |

### 1.3 数据权限
- 功能权限(RBAC) + 项目数据权限(成员关系)
- 高敏感操作单独授权: APK下载/原始报文/录屏/完整报告导出

## 2. 不可信文件处理

- 上传文件先计算哈希、校验类型和大小
- 禁止在Web服务进程中解包APK
- APK分析在隔离Worker中执行，低权限账户
- Worker不挂载数据库凭据，仅获取任务级临时令牌
- 引擎输出按白名单解析，防路径穿越/压缩炸弹
- 动态设备与办公网/生产网隔离

## 3. 传输与存储保护

- 平台/Agent/存储间TLS
- 敏感配置加密存储
- 原始报文/设备标识/账号按敏感等级字段加密或脱敏
- 证据文件按权限受控访问

## 4. 审计与防抵赖

覆盖操作: 登录/任务创建/规则发布/证据访问/报告导出/问题状态变化/误报确认/风险接受/删除
记录: 操作者/时间/来源IP/操作对象/前后值/请求ID
审计日志不可篡改，普通管理员不可修改

## 5. AI安全控制

- AI输入前数据分级和脱敏
- 默认不将APK源码/完整报文/账号/原始个人信息发送外部模型
- 模型输出作为辅助数据，不直接定性
- 系统提示词要求模型只能依据提供证据，不得补造
- AI生成的规则/整改建议发布前需人工审核
