# 引擎适配器设计

## 1. 适配器框架

```
                    ┌──────────────────┐
                    │  TaskOrchestrator │
                    │  (任务编排服务)    │
                    └────────┬─────────┘
                             │
                    ┌────────▼─────────┐
                    │  EngineAdapter    │
                    │  (抽象基类)       │
                    └────────┬─────────┘
                             │
           ┌─────────────────┼─────────────────┐
           │                 │                 │
   ┌───────▼──────┐  ┌──────▼───────┐  ┌─────▼──────┐
   │ StaticAdapter │  │ DynamicAdapter│  │ AnalysisAdapter│
   │ (静态适配器组) │  │ (动态适配器)  │  │ (分析适配器)   │
   └───────────────┘  └──────────────┘  └──────────────┘
```

## 2. 适配器基类

```python
class EngineAdapter(ABC):
    """引擎适配器抽象基类"""

    @abstractmethod
    def get_capabilities(self) -> list[str]:
        """声明适配器能力标签"""

    @abstractmethod
    def validate_environment(self) -> bool:
        """校验运行环境"""

    @abstractmethod
    async def prepare(self, ctx: TaskContext) -> None:
        """准备阶段：下载APK、环境检查"""

    @abstractmethod
    async def execute(self, sub_task: SubTask) -> AdapterResult:
        """执行检测"""

    @abstractmethod
    def normalize_events(self, raw_result: Any) -> list[DetectionEvent]:
        """将原始结果标准化为统一事件"""

    @abstractmethod
    def collect_artifacts(self) -> list[ArtifactRef]:
        """收集产出物引用"""

    async def report_progress(self, percent: int, stage: str, message: str):
        """上报进度"""

    async def cleanup(self):
        """清理临时文件"""

    async def cancel(self):
        """取消执行"""
```

## 3. 静态检测适配器

### 3.1 AndroguardAdapter
- 能力: BASIC_INFO, PERMISSIONS, COMPONENTS, SIGNATURE, STRINGS
- 输入: APK文件路径
- 输出: 基本信息/权限/组件/签名/域名字符串
- 用途: APK基础分析

### 3.2 MobSFAdapter
- 能力: STATIC_SCAN, MALWARE_CHECK, TRACKER_DETECTION
- 输入: APK文件路径
- 输出: MobSF JSON报告
- 用途: 静态扫描+跟踪器检测

### 3.3 AppSharkAdapter
- 能力: DATA_FLOW, TAINT_ANALYSIS
- 输入: APK + Source/Sink规则
- 输出: 数据流路径
- 用途: 深度污点分析

### 3.4 JADXAdapter
- 能力: DECOMPILATION, CODE_SEARCH
- 输入: APK文件路径
- 输出: 反编译Java源码
- 用途: 代码搜索+SDK识别辅助

## 4. 静态检测处理链

```
APK输入
  │
  ▼
[1]输入校验 ──→ 哈希/大小/包名校验
  │
  ▼
[2]基础解包 ──→ AndroguardAdapter
  │               Manifest/DEX/资源/Native/证书/字符串
  │
  ▼
[3]SDK识别 ──→ 指纹匹配引擎
  │               包名+类名+资源+域名多特征
  │
  ▼
[4]敏感API扫描 ──→ AndroguardAdapter
  │                 Source/Sink快速定位
  │
  ▼
[5]深度数据流 ──→ AppSharkAdapter
  │               按规则包执行污点分析
  │
  ▼
[6]结果标准化 ──→ 转换为统一静态事件
  │
  ▼
[7]规则预判 ──→ 静态规则形成"可能风险"
```

## 5. 动态检测适配器

### 5.1 FridaAgentAdapter
- 能力: HOOK, API_TRACE, STACK_TRACE
- 输入: APK + Hook脚本包 + 场景配置
- 输出: 敏感API调用事件(含调用栈)

### 5.2 MitmproxyAdapter
- 能力: TRAFFIC_CAPTURE, TLS_DECRYPT
- 输入: 代理配置
- 输出: HTTP/HTTPS请求事件

### 5.3 UIAutomatorAdapter
- 能力: UI_AUTOMATION, SCREENSHOT
- 输入: 自动化脚本
- 输出: 页面事件+截图

## 6. 统一错误码处理

| 错误码 | 说明 | 策略 |
|--------|------|------|
| ENV_NOT_READY | 环境不满足 | 停止子任务 |
| INPUT_INVALID | APK损坏/包名不一致 | 阻止任务 |
| ENGINE_TIMEOUT | 超时 | 重试/降级 |
| DEVICE_OFFLINE | 设备掉线 | 切换设备 |
| HOOK_FAILED | Frida注入失败 | 切换脚本/人工 |
| TRAFFIC_UNREADABLE | 证书绑定/加密 | 保留连接证据 |
| RESULT_PARSE_ERROR | 输出格式异常 | 保存原始文件 |
