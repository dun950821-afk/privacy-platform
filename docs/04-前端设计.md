# 前端设计

## 1. 技术栈
- Vue 3 + TypeScript + Vite
- Element Plus (组件库)
- Tailwind CSS (原子化样式)
- ECharts (图表)
- Pinia (状态管理)
- Vue Router (路由)

## 2. 主题方案

浅色企业SaaS风：白底 + 蓝灰 + 程式蓝点缀

- 文字主 Text Primary: #1F2329
- 文字次 Text Secondary: #646A73

字体：Inter / -apple-system / "PingFang SC" / "Microsoft YaHei"

## 5. 核心交互

### 5.1 任务创建向导
Step1: 选择App版本 → Step2: 选择检测类型和规则包 → Step3: 配置动态场景 → Step4: 确认提交

### 5.2 任务详情页
- 顶部：任务状态机可视化(进度条)
- 左侧：场景列表+状态
- 右侧：事件时间线(实时刷新)
- 底部Tab：问题/证据/日志

### 5.3 问题详情页
- 左侧：问题信息(标题/等级/场景/API/SDK/域名)
- 右侧Tab：
  - 证据时间线(截图+调用栈+报文)
  - 关联事件
  - 规则依据
  - 整改记录
  - 操作日志

### 5.4 综合看板
- 统计卡片：App数/任务数/待处理问题/高危问题
- 风险趋势图(折线)
- 问题分布(饼图)
- SDK风险排行(柱状图)
- 最近任务(列表)
